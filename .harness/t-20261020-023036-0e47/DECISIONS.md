# DECISIONS

## 1. 로드맵의 "진행" 단계에 무엇을 둘지
- options: 다음 항목 중 하나를 진행으로 표시 / 완료와 다음 사이에 "지금 · now" 마디 하나만 둔다
- chosen: "지금 · now (2026-10 · 공개 준비)" 마디 하나를 진행 색(#D29922)으로 둔다
- why: 명세가 진행 중인 항목을 지정하지 않았고, 다음 항목 중 하나를 임의로 진행이라 하면 사실과 다를 수 있다
- effect: roadmap.svg 의 `<!-- 지금 -->` 부분. 특정 항목을 진행으로 바꾸려면 그 마디 원의 stroke/fill 을 #D29922 로 바꾸면 된다

## 2. 워치독 타이머 원을 실제 0.45 s 로 돌릴지
- options: 실제 시간(0.45 s)으로 채움 / 눈에 보이게 1.5 s 로 늘려 채우고 라벨에 0.45 s 실측값 표시
- chosen: 6 s 주기 안에서 1.5 s 동안 채우고, 원 안·타임라인에 "0.45 s"·"실측 0.45 s / 0.51 s" 를 적는다
- why: 0.45 s 는 너무 빨라 장면이 읽히지 않는다
- effect: dataflow.svg 의 keyTimes(0.5→0.75). 실제 속도로 바꾸려면 0.75 를 0.575 로 바꾼다

## 3. 8번째 지표 카드
- options: 카드 7개 / 센서 주기를 둘로 나눔 / /scan 광선 수(1800)를 따로 카드로
- chosen: 센서 주기 3개는 한 카드에 막대 3줄로, 8번째 카드는 "LiDAR 한 바퀴 1800 광선"
- why: 1800 광선도 명세에 있는 실측값이고 4×2 격자가 고르게 찬다
- effect: metrics.svg 의 `<!-- 8. LiDAR 해상도 -->` 그룹. 빼려면 그 그룹을 지우면 된다

## 4. 애니메이션 없이 볼 때의 모습
- options: 시작 상태(투명·막대 0)를 기본값으로 / 완성 상태를 기본값으로 두고 애니메이션이 덮어쓰게
- chosen: 완성 상태를 기본값으로 둔다(막대 width 는 목표값, 카드 opacity 기본 1, 패킷 begin 은 음수)
- why: 애니메이션을 끈 뷰어·썸네일에서도 내용이 보여야 한다. 대신 막대가 카드별로 늦게 시작하는 효과는 뺐다
- effect: metrics.svg 막대 애니메이션에 begin 이 없음. 다시 엇갈리게 하려면 values/keyTimes 에 지연 구간을 넣는다
